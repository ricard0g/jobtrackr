Preguntas Frecuentes

Si tienes alguna duda escribenos desde el formulario de contacto.

Necesito crear una cuenta para usar JobTrackr?
No necesitas cuenta porque ahora mismo la aplicacion esta bajo desarrollo. Solo contamos con un usuario ficticio para que usuarios de visita prueben y jueguen un poco con la aplicacion.
Mis datos se guardan si cierro el navegador?
Sí. JobTrackr guarda tus candidaturas en una base de datos para que estén disponibles cada vez que vuelvas. No se pierden al cerrar la pestaña.
Puedo usarlo desde el móvil?
Sí. La interfaz está diseñada para funcionar en cualquier dispositivo, aunque la experiencia es especialmente cómoda desde escritorio.
Cuántas candidaturas puedo añadir?
Las que necesites. No hay ningún límite en el número de tarjetas ni de columnas activas.
Qué pasa cuando encuentro trabajo?
Dejarlo solo para seguir usando JobTrrackr... Es broma, Enhorabuena! Puedes marcar esa candidatura como Oferta aceptada y seguir usando el tablero para otras oportunidades, o simplemente cerrarlo. Es tu herramienta.
JobTrackr tiene acceso a mis datos personales?
No. La aplicación solo guarda la información que tú introduces voluntariamente: nombre de la empresa, puesto y tus notas. No hay rastreo, no hay analítica de usuario.
Quién ha creado esto?
JobTrackr es un proyecto desarrollado como parte del ciclo formativo de Desarrollo de Aplicaciones Web. Está construido con tecnologías web estándar y un backend en Java. Puedes ver el código completo en GitHub.
