# Build the public landing with Astro

The public landing will be a separate static Astro project hosted on Vercel at `https://jobtrakcr.com`. A simple, standalone React replica of the app's visible screens will live at `/demo` and appear immediately below the hero inside a same-origin `<iframe src="/demo">`; HTML and CSS around the frame will provide a decorative Safari-style browser bar without blocking interaction. Visitors may move fictional Kanban cards, inspect prepared Application details and CV Generation history, and preview prepared fictional CVs in Documents; they cannot create or edit records, upload or download files, or generate CVs. The demo uses local state, no real authentication or API calls, and resets on reload; the signed-in JobTrackr application remains on the VPS at `https://app.jobtrakcr.com`. The source page's FAQ stays, its nonfunctional contact form is removed, and the footer provides a contact email instead; `support@jobtrakcr.com` is the placeholder, to be routed to an existing inbox before launch. The footer also links to Terms, Privacy, and Cancellation/Refund pages available before payment.
